# 后端接口手册（权威清单）

> 结论以当前仓库 Controller 代码为准。小程序只调用 `/api/**`（及公开 `/public/**`）；管理端页面与 JSON 走 `/fire/**`、`/common/**`、`/system/**`。  
> 已知契约断点与小程序适配说明见 [04-前后端API契约.md](04-前后端API契约.md)。

## 1. 通用约定

### 鉴权

| 规则 | 路径 | 说明 |
|---|---|---|
| anon | `POST /api/login`、`POST /api/wx/login`、`POST /api/register`、`GET /api/register/invite/resolve`、`GET /api/fire/dept/list`、`/public/**` | 无需登录 |
| apiToken | `/api/**`（anon 除外） | Header：`Authorization: Bearer <Shiro SessionId>` |
| Admin | `/fire/**`、`/common/**` | Cookie Session + `@RequiresPermissions` |

### 响应

- 普通：`{ code: 200|0, msg, data }`
- 分页：`{ code: 0|200, msg, rows, total }`
- 小程序应同时处理 **HTTP 401** 与 **body.code === 401**

### 分页（小程序）

列表接口优先使用 **URL query**：`?pageNum=1&pageSize=10`。  
部分接口同时支持 JSON body 内的 `pageNum/pageSize`（兼容旧客户端）。新原生小程序统一走 query。

## 13. 小程序薄前端原则

1. 不内嵌业务字典大表；类目走模板/字典 API。  
2. 不做越权判断；按钮展示可参考后端字段，最终以后端校验为准。  
3. 不做列表本地二次过滤代替服务端筛选（任务类型、日期、设备分组等）。  
4. 失败展示后端 `msg`，禁止假数据兜底掩盖接口错误。  
5. 唯一请求层：`miniprogram/services/request.js`。
